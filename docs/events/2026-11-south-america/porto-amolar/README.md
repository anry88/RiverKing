# Ноябрь: Порту-Амолар — предложение для согласования

Подготовлено 28 октября 2026 года по замечанию пользователя: ивент должен представлять конкретное реальное место, с узнаваемым фоном и подходящими рыбами. Пользователь дополнительно попросил короткое название для интерфейсов.

- **RU:** Порту-Амолар (12 знаков).
- **EN:** Porto Amolar (12 знаков).
- **Место:** река Парагвай у Порту-Амолар, Серра-ду-Амолар, Пантанал, Бразилия. Это населённый пункт выше Корумбы по реке, а не городской берег Корумбы.
- [Найти место на карте](https://www.google.com/maps/search/?api=1&query=Porto+Amolar+Corumba+Brazil).
- Короткое описание: «Река Парагвай у подножия Серра-ду-Амолар. Широкая вода, пойменные леса и скалистые склоны Пантанала».

Статус: **предложение, не опубликовано**. Рабочий `event.json` и запись ID 5 пока сохраняют прежние настройки. Подготовка этого варианта не меняет HDC, расписание, базу игроков или клиентские сборки.

## Фон

![Предложенный фон Порту-Амолар](background.png)

Новый фон создан встроенным `imagegen`, а не взят из фотобанка. Запрос сохранён в [proposal.json](proposal.json). Ориентиры — реальные фотографии Серра-ду-Амолар: скалистые покрытые лесом склоны над широкой пойменной рекой. Это художественная реконструкция местного пейзажа, не документальная фотография конкретного берега. Центральная и нижняя часть кадра оставлена под вываживание и заброс.

## Предлагаемый пул: 37 рыб

Полный список, латинские названия, редкости, игровые группы наживки и кандидаты на повторное использование ассетов сохранены в [proposal.json](proposal.json). Распределение по редкостям остаётся **11 / 7 / 7 / 5 / 4 / 3**. Семь новых рыб из первой версии сохраняются.

| Редкость | Состав |
|---|---|
| Common · 11 | Куримбата; Тетра чёрный неон; Тетра минор; Афиохаракс Анизица; Тетрагоноптерус серебристый; Моэнкаузия дихроура; Чёрный фантом; Хемиграммус Ульрея; Пиррулина южная; Цихлазома мезонаута; Сайканга Кинкейда |
| Uncommon · 7 | Пирапутанга; Тернеция чёрная; Филомена; Прионобрама парагвайская; Метиннис мола; Лепоринус трёхпятнистый; Пиранья краснобрюхая |
| Rare · 7 | Пиавусу; Паку пантанальский; Ацестроринх Пантанала; Креницихла ленточная; Пиранья окаймлённая; Пиранья пятнистая; Траира |
| Epic · 5 | Качара; Сом веслоносый; Журупока; Пальмито; Пимелодус украшенный |
| Mythic · 4 | Скат Фалькнера; Скат моторо; Барбадо; Пати |
| Legendary · 3 | Дорадо золотой; Пинтадо; Жау |

Названия новых карточек пока рабочие. Основание списка — бассейн верхнего Парагвая и связанная пойма Пантанала; присутствие всех 37 видов непосредственно у одного выбранного берега не заявляется. Названия в источниках местами соответствуют прежней систематике; это не повод создавать дубли одного вида.

Вариант требует **24 новых карточек/изображений**. Для 13 позиций есть кандидаты в текущем каталоге, включая все семь уже добавленных рыб; для «Сома веслоносого» перед повторным использованием нужно подтвердить соответствие изображения *Sorubim lima*. Не переименовывать глобальные амазонские карточки в похожие местные виды. Например, местный паку *Piaractus mesopotamicus* и жау *Zungaro jahu* нельзя без проверки подменить существующими общими названиями «Паку краснобрюхий» и «Зунгаро».

Из первой версии исключены арапайма, электрический угорь, краснохвостый сом, аймара, паяра, амазонская рыба-лист и другие позиции без достаточного основания для выбранного бассейна. Часть подходящих видов заменяет рыб в тех же редкостях; тернеция и сом веслоносый дополнительно берутся из общего каталога.

## Баланс и применение после согласования

Даты сохраняются: **01.11.2026 00:00 UTC — 01.12.2026 00:00 UTC**. Награды и зачёты прежние. Базовые суммы весов по редкости и игровой группе наживки должны остаться равны утверждённому ноябрьскому варианту и образцу «Ущелье Колумбии». Облегчение дают только глобальные множители rare ×1,3 / epic ×2 / mythic ×3 / legendary ×3. В предложении сохранены количества мирных/хищных игровых позиций по каждой редкости; численные веса пока не назначены.

После согласования названия, фона и состава: подготовить недостающие изображения, обновить манифест и клиентские ассеты/отображение, проверить баланс и мобильный кроп. Выпустить через `develop → main`; HDC получает готовые локальные артефакты без тяжёлой серверной сборки. Обновить существующий будущий ивент **ID 5**, сохранив его расписание, награды и идентичность. Новый ивент рядом не создавать.
