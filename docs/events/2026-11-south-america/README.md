# Ноябрь 2026: Порту-Амолар

Задача: [AND-18 — Создать ноябрьский ивент в Южной Америке](https://linear.app/andrei-brazhnikov/issue/AND-18/sozdat-noyabrskii-ivent-v-yuzhnoi-amerike).

Название, фон, полный пул и шесть дополнительных рисунков утверждены пользователем 28 октября 2026 года. **37 рыб = 13 новых для ноября (7 ранее готовых + 6 дополнительных) и 24 старые.** [Полный список и утверждённые изображения](porto-amolar/README.md), [рабочий манифест](event.json). Контент интегрирован в общий каталог, Mini App, Android и карточки улова бота.

Место — река Парагвай у Порту-Амолар, Серра-ду-Амолар, Пантанал, Бразилия. Пул является игровой подборкой Южной Америки: стопроцентное совместное обитание всех рыб в одной точке не заявляется. Существующие виды используются со своими названиями и картинками; один вид — одно самостоятельное изображение. Арапайма из ноябрьского пула исключена; легендарная тройка — **дорадо золотой, пинтадо и жау**.

Production **ID 5** обновляется после слияния контентного релиза и его развёртывания; при старте сервера ивент автоматически не создаётся и не переписывается.

## Даты, зачёты и награды

Даты по [общему правилу создания ивентов](../README.md): **1 ноября 2026 00:00 UTC — 1 декабря 2026 00:00 UTC**, то есть **01:00 по Белграду** на обе даты. Начало и окончание соответствуют полуночи UTC, как при создании через Android-админку; текстовые даты в исторической SQL-выгрузке не задают расписание нового ивента. Доступ через членство в клубе; прогресс — общий вес клуба, количество улова клуба и лучшая рыба игрока. Используются существующие лидерборды, история и выдача EVENT-призов без нового API и отдельных механик заданий.

25 октября 2026 года обе даты исправлены в существующей рабочей записи **ID 5** через admin API. Состав из 37 рыб, веса, награды и зона заброса сверены после изменения; повторный импорт распознаёт ту же запись без дубликата.

Награды скопированы из последних ивентов: три клубных места по весу (`autofish`, две недели автоловли, неделя автоловли), три места по количеству (3/2/1 `bundle_whale`), десять личных мест (10000/9000/…/1000 монет). Утверждённый фон показывает реальную характерную местность Серра-ду-Амолар у реки Парагвай; многоугольная зона заброса исключает ближний берег.

## Баланс

По последнему указанию пользователя дополнительного облегчения в базовых весах нет. За образец взяты реальные веса «Ущелья Колумбии» с поправкой на пресную воду (`×0,65` для прежних морских видов) и соответствие хищной/мирной наживки (`×0,18` при несовпадении).

Суммарные базовые веса сохранены по каждой редкости и типу питания. Исключение — legendary: в новом пуле все три вида хищные, тогда как в прошлом был мирный белый осётр. Их общий вес выставлен так, чтобы на пресную хищную наживку суммарная вероятность legendary совпадала с прошлой. Для мирной наживки вероятность legendary ниже; изменение обусловлено составом видов.

После этого применяются только общие множители `rare ×1,3`, `epic ×2`, `mythic ×3`, `legendary ×3`. Расчёт с равномерным ожиданием 5–30 секунд, без бонуса редкости наживки, для пресной хищной наживки:

| Редкость | Старая формула / ноябрь без множителей | Ноябрь с общими множителями |
|---|---:|---:|
| Rare | 23,083% | 26,925% |
| Epic | 1,468% | 2,633% |
| Mythic | 1,045% | 2,809% |
| Legendary, все виды вместе | 0,060% | 0,161% |

Это шансы выбора редкости, а не конкретной рыбы и не гарантия времени до улова. Бонус редкости наживки, ожидание, тип наживки и последующее вываживание меняют результат. Числа и оговорки сохранены в [balance.json](balance.json). Тест проверяет равенство базовых весов с историей, а не случайную выборку уловов.

## Публикация и настройка

1. Выпустить изменения через обычный PR develop → main и развернуть готовый образ, собранный локально. **Не запускать тяжёлую Docker/Gradle-сборку на HDC.** Фон доставляется из `data/event-assets/porto_amolar.png`.
2. Сохранить текущие настройки будущего ивента **ID 5** и обновить эту же запись через `PUT /api/admin/events/5` по [event.json](event.json), разрешив имена рыб через каталог. До записи проверить будущие даты и отсутствие пересечений. Не создавать второй ивент на те же даты.
3. Перечитать запись и сверить все 37 рыб, веса, UTC-даты, награды, фон и зону. После обновления запустить обычную проверку без записи:

   ```bash
   python3 scripts/configure-event.py docs/events/2026-11-south-america/event.json --base-url https://riverking.tg-games.com
   ```

Скрипт создания намеренно не перезаписывает отличающуюся существующую запись: переименование и замена состава выполняются через PUT, затем проверка распознаёт тот же ID без дубликата. Токен передаётся через окружение и не сохраняется в манифесте.

Контракт сервера не меняется. Предыдущий выпущенный Android безопасно продолжает игру: неизвестная локальная картинка заменяется заглушкой, а фон события доступен через imageUrl. Для шести новых спрайтов нужен свежий APK; принудительное повышение минимальной версии не требуется.

## Основания для региональной подборки

- [Embrapa: Recursos pesqueiros do Pantanal](https://www.embrapa.br/en/web/pantanal/recursos-pesqueiros) — региональная тема и характерные промысловые рыбы, включая dourado, pintado и cachara.
- [Академия наук Бразилии: Biomas e Agricultura, 2025](https://www.abc.org.br/wp-content/uploads/2025/03/Livro-Biomas-e-Agricultura-Site.pdf) — таблица рыб бассейна верхнего Парагвая с Prochilodus lineatus, Brycon hilarii, Megaleporinus macrocephalus и двумя Pseudoplatystoma.
- [SciELO: Potamotrygon falkneri и P. motoro](https://www.scielo.br/j/ni/a/DCP3tWhsbYrDRjnmPdLWPMG/?lang=en) — региональное основание для ската Фалькнера.
- Существующие игровые названия, редкости и изображения взяты из `Tables.kt` и `webapp/scripts/shared.js`. Для всех существующих видов не заявляется совместное обитание в одной реке Пантанала.
